# Skills help

## Create a skill
In the Skills panel, click **New**. Choose the name and storage location
(global or a specific project), then edit the generated `SKILL.md`.

## Run a skill
Select a skill and use the **Run** action. Pick the target project when
prompted; progress appears in Background Work, and output opens on completion.

## Edit frontmatter
The authoring form edits the skill's frontmatter — name, description, and
declared inputs. Changes are saved back into the `SKILL.md` header.

## Scope a skill to a project
A project-scoped skill lives under that project's `.claude/skills`. Use the
scope control to move a skill between global and project scope.
