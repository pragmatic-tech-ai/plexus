# TodlSolutionsDevelopment Module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new `plexus-core` module `todl-solutions-development` with a project-explorer-parity `SolutionExplorerService` that drives TODL's shipped solution engine, rendering an `OpenSolution → OpenProject(members) → files` tree with full New/Open/Add-member/Remove-member/Save lifecycle; devUI adopts it in place of its current solution module.

**Architecture:** The module owns its own tree (`OpenSolution` root VM whose `Members` are `OpenProject` reused verbatim). Member file trees are built by a **new** generic `ProjectTreeScanner` (`IStorage` → `ProjectNode` tree) and wrapped by a minimal `FolderProjectFactory`, so `OpenProject` is reused unchanged and **Project Explorer is not touched at all**. The service drives TODL's `SolutionManagerService`/`SolutionViewService` directly — `plexus-core`'s `todl-runtime`-only dependency floor is deliberately relaxed to add `@pragmatic-tech-ai/todl`. Host seams: `StorageService` already satisfies `IStorageProviderRegistry` (its `CreateStorage`), a new core `DiscardConfirmer` satisfies `IDiscardConfirmer`; the app supplies `IProjectFactoryRegistry` + `PackageSource`.

**Tech Stack:** mural (`ServiceBase`, `ServiceKey`, `ObservableCollection`, `MuralBase`, `RelayCommand`, `DataTemplate`, `.mu`), `@pragmatic-tech-ai/todl` (solution engine), `@pragmatic-tech-ai/todl-runtime` (`IStorage`, `FakeStorage`, `compareStorageEntries`), electron-vite, vitest.

**Spec:** `docs/superpowers/specs/2026-09-18-todl-solutions-development-design.md`

## Global Constraints

- **Dependency floor (relaxed):** `plexus-core` may now import `@pragmatic-tech-ai/todl` **only** from within `renderer/modules/todl-solutions-development/**` (and its own `package.json`). The rest of `plexus-core` keeps its `mural` + `todl-runtime`-only floor. No new `@pragmatic-tech-ai/todl` imports elsewhere.
- **No regression to Project Explorer:** nothing under `renderer/modules/project-explorer/**` or `renderer/projects/{open-project,project,project-factory}.ts` is modified. New shared code is *added* to `renderer/projects/`.
- **OOP, no globals (user CLAUDE.md):** every function is a class method (private `static` for helpers). No module-level free functions, no module-level mutable state. Module-level `const` for true constants and `type`/`enum`/`interface` declarations is fine.
- **PascalCase (user CLAUDE.md):** all interfaces and all public methods/properties are PascalCase (`Scan`, `AddMember`, not `scan`/`addMember`). Private members and serialized-JSON data shapes keep their existing casing.
- **VMs extend `Observable`** by default. Exception, explicitly justified per task: `OpenSolution` extends `MuralBase` because it is rendered through DP bindings in a `DataTemplate` and mirrors `OpenProject`/`ProjectNode` (the spec permits tree nodes to extend `MuralBase` for parity).
- **Enums over string-literal unions** for any new closed set.
- **Tests:** every test file lives in a `tests/` subfolder next to the code it exercises. Runner: `vitest` (globs `src/**/*.test.ts`).
- **`.mu.js`** are gitignored and regenerated by `compile:mu` (plexus-core) / the vite build (apps) — never hand-edited, never committed.
- **Commit only when a task says to.** Do not push. End commit messages with the `Co-Authored-By` trailer.

## Plan rulings (deviations from the spec, recorded for the executor)

1. **Shared node-builder is new, not extracted.** The spec said "extracted shared node-builder." The reusable primitive (folder-scan → `ProjectNode` tree) does not live in `ProjectExplorerService`; it lives in each app factory (`TodlProjectFactory.populate`). So this plan **adds** a generic `ProjectTreeScanner` to `renderer/projects/` and leaves Project Explorer and the app factories untouched. This honors "no regression" more strictly than an extraction would.
2. **Compose is deferred out of the first slice.** The spec's Decision 4 lists "`Compose` diagnostics surfaced as `Status`." Producing the `PackageRef[]` that `SolutionManagerService.Compose` needs requires compiling each member against a registry connection — the app/IPC path the spec **also** defers (connection-picker UI is a later slice). The first-slice toolbar is therefore **New / Open / Add member / Remove member / Save** with a `Status` line; `Compose` and the connection picker are a later slice. Consequence: devUI temporarily loses its connection picker + Compose button (see Phase 5). This is a solution-module change, not a Project-Explorer regression.

```ts
// project-tree-scanner.ts
import { compareStorageEntries, type IStorage } from '@pragmatic-tech-ai/todl-runtime'
import { ProjectNode, type ProjectNodeKind } from './project.js'
import type { ProjectFileFormat } from './project-factory.js'

// Options controlling a scan: files to hide at the root (e.g. the project
// manifest) and the format table that maps a file extension to a node kind.
export interface ProjectTreeScanOptions
{
    HiddenRootFiles?: readonly string[]
    Formats?: readonly ProjectFileFormat[]
}

// Turns a rooted IStorage into a ProjectNode file tree — the generic folder walk
// (project-relative POSIX paths, folders before files) that ProjectExplorer's
// concrete factories perform inline, lifted here so a solution member's tree can
// be built without a concrete project factory. The root node's path is '' and its
// name is the last segment of storage.Root; children recurse depth-first.
export class ProjectTreeScanner
{
    public async Scan(storage: IStorage, options: ProjectTreeScanOptions = {}): Promise<ProjectNode>
    {
        const root = new ProjectNode(ProjectTreeScanner.basename(storage.Root), '', 'folder')
        await this.populate(storage, root, options)
        return root
    }

    private async populate(storage: IStorage, node: ProjectNode, options: ProjectTreeScanOptions): Promise<void>
    {
        const hidden = options.HiddenRootFiles ?? []
        const entries = [...await storage.List(node.Path)].sort(compareStorageEntries)
        for (const entry of entries)
        {
            if (node.Path === '' && hidden.includes(entry.Name)) continue
            const childPath = node.Path === '' ? entry.Name : `${node.Path}/${entry.Name}`
            const kind: ProjectNodeKind = entry.IsDirectory ? 'folder' : this.kindForFile(entry.Name, options.Formats ?? [])
            const child = new ProjectNode(entry.Name, childPath, kind)
            node.Children.Add(child)
            if (entry.IsDirectory) await this.populate(storage, child, options)
        }
    }

    private kindForFile(name: string, formats: readonly ProjectFileFormat[]): ProjectNodeKind
    {
        const ext = ProjectTreeScanner.extname(name)
        const fmt = formats.find((f) => f.extension === ext)
        return fmt !== undefined ? (fmt.kind as ProjectNodeKind) : 'file'
    }

    private static basename(p: string): string
    {
        const parts = p.split(/[\\/]/)
        return parts[parts.length - 1] || p
    }

    private static extname(name: string): string
    {
        const i = name.lastIndexOf('.')
        return i > 0 ? name.slice(i).toLowerCase() : ''
    }
}
```

```ts
// folder-project-factory.ts
import type { IStorage } from '@pragmatic-tech-ai/todl-runtime'
import { Project } from './project.js'
import { ProjectTreeScanner } from './project-tree-scanner.js'
import {
    PROJECT_MANIFEST_FILENAME,
    type IProjectFactory,
    type ProjectFileFormat,
    type ProjectManifestEnvelope,
} from './project-factory.js'

// A minimal IProjectFactory that treats any folder as a project: openProject
// scans the folder into a Project (hiding the manifest at the root), so a
// solution member — opened by the TODL engine as a bare name+storage handle —
// can be wrapped in an OpenProject and rendered by the same tree templates as a
// standalone project. It does not create or persist projects (a member already
// exists on disk); createProject throws and saveProject is a no-op.
export class FolderProjectFactory implements IProjectFactory
{
    public readonly formats: readonly ProjectFileFormat[] = []

    public async openProject(storage: IStorage): Promise<Project>
    {
        const manifest = await this.readManifest(storage)
        const root = await new ProjectTreeScanner().Scan(storage, { HiddenRootFiles: [PROJECT_MANIFEST_FILENAME] })
        const name = manifest?.name ?? FolderProjectFactory.basename(storage.Root)
        const type = manifest?.type ?? 'folder'
        return new Project(type, name, storage.Root, root)
    }

    public async createProject(): Promise<Project>
    {
        throw new Error('FolderProjectFactory does not create projects.')
    }

    public async saveProject(): Promise<void> { /* members persist through their own tooling */ }

    private async readManifest(storage: IStorage): Promise<ProjectManifestEnvelope | undefined>
    {
        try { return JSON.parse(await storage.ReadText(PROJECT_MANIFEST_FILENAME)) as ProjectManifestEnvelope }
        catch { return undefined }
    }

    private static basename(p: string): string
    {
        const parts = p.split(/[\\/]/)
        return parts[parts.length - 1] || p
    }
}
```

```ts
// open-solution.ts
import { MetaData, MuralBase, ObservableCollection } from '@pragmatic-tech-ai/mural/runtime'
import type { OpenProject } from '../../../projects/open-project.js'

// One open solution — the tree's ROOT row, mirroring OpenProject. Its Members are
// OpenProjects (reused verbatim), so each member renders with the same file-tree
// templates as a standalone project. Extends MuralBase (not Observable) because it
// is bound through dependency properties in the solution tree DataTemplate.
export class OpenSolution extends MuralBase
{
    static readonly NameKey = MuralBase.RegisterProperty<string>(OpenSolution, 'Name', '', MetaData.None)
    static readonly RootPathKey = MuralBase.RegisterProperty<string>(OpenSolution, 'RootPath', '', MetaData.None)
    static readonly MembersKey = MuralBase.RegisterProperty<ObservableCollection<OpenProject>>(
        OpenSolution, 'Members', undefined as unknown as ObservableCollection<OpenProject>, MetaData.None)
    static readonly IsDirtyKey = MuralBase.RegisterProperty<boolean>(OpenSolution, 'IsDirty', false, MetaData.None)

    constructor(name: string, rootPath: string)
    {
        super()
        this.set_property_value(OpenSolution.NameKey, name)
        this.set_property_value(OpenSolution.RootPathKey, rootPath)
        this.set_property_value(OpenSolution.MembersKey, new ObservableCollection<OpenProject>())
        this.set_property_value(OpenSolution.IsDirtyKey, false)
    }

    public get Name(): string { return this.get_property_value(OpenSolution.NameKey) }
    public set Name(v: string) { this.set_property_value(OpenSolution.NameKey, v) }
    public get RootPath(): string { return this.get_property_value(OpenSolution.RootPathKey) }
    public get Members(): ObservableCollection<OpenProject> { return this.get_property_value(OpenSolution.MembersKey) }
    public get IsDirty(): boolean { return this.get_property_value(OpenSolution.IsDirtyKey) }
    public set IsDirty(v: boolean) { this.set_property_value(OpenSolution.IsDirtyKey, v) }
}
```

```ts
// discard-confirmer.ts
import type { DialogService } from '@pragmatic-tech-ai/mural/framework'
import type { IDiscardConfirmer } from '@pragmatic-tech-ai/todl'
import { ConfirmDialogModel } from '../../../dialogs/confirm-dialog-model.js'

// Prompts to discard unsaved solution changes via the shared Mural dialog. Keeps
// SolutionManagerService UI-agnostic: the copy + DialogService live on this side
// of the engine's IDiscardConfirmer seam. Core (not app) because the dialog and
// its copy are generic. Interface method stays camelCase — it is the TODL
// engine's external contract.
export class DiscardConfirmer implements IDiscardConfirmer
{
```

```ts
// solution-explorer-service.ts
import {
    ObservableCollection,
    ServiceBase,
    ServiceKey,
    type IServiceProvider,
} from '@pragmatic-tech-ai/mural/runtime'
import {
    SolutionManagerService,
    type SolutionMember,
    type SolutionViewService,
} from '@pragmatic-tech-ai/todl'
import { StorageService } from '../../storage/index.js'
import { OpenProject } from '../../../projects/open-project.js'
import { FolderProjectFactory } from '../../../projects/folder-project-factory.js'
import { OpenSolution } from './open-solution.js'

// The Solution Explorer panel service — the solution-level analogue of
// ProjectExplorerService. It drives TODL's headless SolutionManagerService and
// projects the ActiveSolution into its OWN tree: one OpenSolution whose Members
// are OpenProjects (reused verbatim, backed by FolderProjectFactory), so members
// render with the same file-tree templates as standalone projects. Lifecycle
// commands + member file-open are added in later tasks.
export class SolutionExplorerService extends ServiceBase
{
    public static readonly Key = new ServiceKey<SolutionExplorerService>('SolutionExplorerService')

    private readonly _openSolutions = new ObservableCollection<OpenSolution>()
    private _status = 'No solution open.'
    private readonly factory = new FolderProjectFactory()

    constructor(provider: IServiceProvider)
    {
        super(provider)
        // Re-project whenever the active solution changes.
        this.manager.PropertyChanged('ActiveSolution').subscribe(() => void this.Refresh())
    }

    public get OpenSolutions(): ObservableCollection<OpenSolution> { return this._openSolutions }
    public get Status(): string { return this._status }

    protected set Status(v: string)
    {
        const old = this._status
        this._status = v
        this.RaisePropertyChanged('Status', old, v)
    }

    private get manager(): SolutionManagerService { return this.Provider.getRequired(SolutionManagerService.Key) }
    private get storage(): StorageService { return this.Provider.getRequired(StorageService.Key) }

    // Rebuild the tree from the manager's ActiveSolution. Async because members
    // are scanned from storage; the collection is repopulated wholesale (0 or 1
    // solution — the manager holds one active at a time).
    protected async Refresh(): Promise<void>
    {
        const session = this.manager.ActiveSolution
        this._openSolutions.Clear()
        if (session === undefined) { this.Status = 'No solution open.'; return }

        const sol = new OpenSolution(session.Name, session.Storage.Root)
        sol.IsDirty = session.IsDirty
        for (const member of session.Members.ToArray())
        {
            sol.Members.Add(await this.BuildMember(session, member))
        }
        this._openSolutions.Add(sol)
        this.Status = `Opened ${session.Name}.`
    }

    // Build one member's OpenProject: root a storage at the member's folder,
    // scan it into a Project (FolderProjectFactory), and wrap it. File-open
    // wiring is added in a later task.
    protected async BuildMember(session: SolutionViewService, member: SolutionMember): Promise<OpenProject>
    {
        const location = SolutionExplorerService.joinOs(session.Storage.Root, member.Ref.path)
        const memberStorage = this.storage.Create(StorageService.DefaultBackendId, location)
        const project = await this.factory.openProject(memberStorage)
        return new OpenProject(project, this.factory, memberStorage)
    }

    // Join a (possibly Windows) root folder with a relative POSIX member path
    // using the root's separator — mirrors LocalFileStorage's abs().
    private static joinOs(root: string, rel: string): string
    {
        const sep = root.includes('\\') && !root.includes('/') ? '\\' : '/'
        const segments: string[] = []
        for (const seg of rel.split(/[\\/]+/))
        {
            if (seg === '' || seg === '.') continue
            if (seg === '..') segments.pop()
            else segments.push(seg)
        }
        if (segments.length === 0) return root
        const base = root.endsWith(sep) ? root.slice(0, -sep.length) : root
        return base + sep + segments.join(sep)
    }
}
```

```ts
// Add a member: pick a project folder that lives UNDER the solution root, derive
// its solution-relative POSIX path, read its declared type from the manifest,
// register it on the session, save, and let the refresh rebuild the tree.
private async addMember(): Promise<void>
{
    const session = this.manager.ActiveSolution
    if (session === undefined) { this.Status = 'No solution open.'; return }
    const dir = await this.fs.OpenFolder({ Title: 'Add member — choose a project folder' })
    if (dir === null) return

    const rel = SolutionExplorerService.relativePosix(session.Storage.Root, dir)
    if (rel === undefined) { this.Status = 'A member must live inside the solution folder.'; return }

    const memberStorage = this.storage.Create(StorageService.DefaultBackendId, dir)
    let type: string
    try {
        const manifest = JSON.parse(await memberStorage.ReadText(PROJECT_MANIFEST_FILENAME)) as { type?: string }
        if (typeof manifest.type !== 'string') { this.Status = 'That folder has no project manifest.'; return }
        type = manifest.type

}

private async removeMember(op: OpenProject): Promise<void>
{
    const session = this.manager.ActiveSolution
    if (session === undefined) return
    const rel = SolutionExplorerService.relativePosix(session.Storage.Root, op.Folder)
    const member = session.Members.ToArray().find((m) => m.Ref.path === rel)
    if (member === undefined) { this.Status = 'That member is no longer in the solution.'; return }
    session.RemoveMember(member)
    await this.manager.Save()
    await this.Refresh()
    this.Status = `Removed ${member.Ref.path}.`
}

// The POSIX-relative path from `root` to `child` when `child` is under `root`,
// else undefined. Case-sensitive; both are absolute OS paths.
private static relativePosix(root: string, child: string): string | undefined
{
    const norm = (p: string): string[] => p.split(/[\\/]+/).filter((s) => s !== '' && s !== '.')
    const r = norm(root), c = norm(child)
    if (c.length < r.length) return undefined
    for (let i = 0; i < r.length; i++) if (r[i] !== c[i]) return undefined
    return c.slice(r.length).join('/')
}
```

The real `SolutionViewService` mutates its own `Members`; the manager does not re-signal `ActiveSolution` on member changes either, so the explicit refresh is correct in production too.

```ts
// In BuildMember, after constructing `project`, wire the tree and keep the storage:
protected async BuildMember(session: SolutionViewService, member: SolutionMember): Promise<OpenProject>
{
    const location = SolutionExplorerService.joinOs(session.Storage.Root, member.Ref.path)
    const memberStorage = this.storage.Create(StorageService.DefaultBackendId, location)
    const project = await this.factory.openProject(memberStorage)
    const op = new OpenProject(project, this.factory, memberStorage)
    this.wireNodes(op.Root, memberStorage)
    return op
}

// Give every node in a member's tree an OpenCommand that opens the file through
// the content host (folders no-op). Mirrors ProjectExplorerService.wireNodes'
// file-open concern — the only per-node behavior a solution member needs in this
// slice (no rename/delete/import).
private wireNodes(node: ProjectNode, storage: IStorage): void
{
    node.OpenCommand = new RelayCommand(() => void this.openNode(node, storage))
    for (const child of node.Children.ToArray()) this.wireNodes(child, storage)
}

private async openNode(node: ProjectNode, storage: IStorage): Promise<void>
{
    if (node.Kind === 'folder') return
    const factory = this.resolveDocumentFactory(SolutionExplorerService.extname(node.Path))
    try {
        if (factory !== undefined) {
            const doc = await factory.openFile(storage, node.Path)
            this.host.Open(doc)
            this.Status = `Opened ${node.Name}.`
        } else if (isLocalFileAccess(storage)) {
            await storage.OpenExternal(node.Path)
        } else {
            this.Status = `Can't open ${node.Name} — no editor for its type.`
        }
    } catch (e) {
        this.Status = `Open failed: ${(e as Error).message}`
    }
}

private get host(): DocumentsContentHostService
{
    return this.Provider.getRequired(ContentHostService.Key) as DocumentsContentHostService
}

// Resolve the editor for a file extension via the framework DocumentTypeRegistry
// (class → token normalization mirrors ProjectExplorerService.resolveDocumentFactory).
private resolveDocumentFactory(ext: string): IDocumentFactory | undefined
{
    const registry = this.Provider.get(DocumentTypeRegistry.Key)
    const def = registry?.GetByExtension(ext)
    if (def?.Factory === undefined) return undefined
    const token = ServiceProvider.tokenFor(def.Factory as unknown as new (...args: never[]) => IDocumentFactory)
    return this.Provider.get(token) as IDocumentFactory | undefined
}

private static extname(p: string): string
{
    const i = p.lastIndexOf('.')
    return i > 0 ? p.slice(i).toLowerCase() : ''
}
```
